## ✨ Features & 4-in-1 Consolidated Modules

1. **🔍 Monkes Explorer (主浏览器)**
   - 10,000 NodeMonkes full inscription dataset search (by ID or Inscription number).
   - Filter by 33 Body traits, sort by Rarity Rank, ID, Inscription, and Block height.
   - **Dual View Mode**: ▦ Modern Grid Gallery & ☷ Compact Data Table with live Script PubKey copy.
   - Interactive Detail Modal with rarity breakdowns and color palette extraction.

2. **🎬 GIF Studio (动图工坊)**
   - Real-time HTML5 Canvas nodding animation simulation.
   - Background options: Transparent, Auto Body-Color Matching, Custom Web3 Palette.
   - Adjustable FPS, Scale resolution (1x to 8x HD), and instant client-side `.gif` export using Web Worker.

3. **🎨 DIY Studio (捏猴换装工坊)**
   - Layer-by-layer canvas avatar builder: Body, Head wear, Laser eyes, Visors, Earrings.
   - 🎲 1-Click "Randomize" generator & Reset button.
   - High-Res 560px PNG export.

4. **🎅 Santa Monkes (圣诞限定款画廊)**
   - 10,000 Santa Hat edition NodeMonkes viewer and avatar creator.
   - Custom festive color palettes and multi-resolution PNG downloads.

## 🚀 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

## 📦 Deployment

This repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`). Pushing to the `main` branch automatically builds and deploys the latest version to GitHub Pages.
